# Таплинк Айзиля — Изумруд

Официальная активная версия таплинка визажиста Айзили в изумрудно-золотой палитре.

**Публичная ссылка:** https://irekgai111-lang.github.io/irke/aizilya/

## Палитра

- Emerald: `#0F4E38`, `#185844`
- Forest: `#102F27`
- Sage: `#78947F`
- Ivory: `#F2EBDD`
- Champagne: `#E3D6B3`
- Antique Gold: `#B08A4F`

## Содержимое

- Главная страница: `index.html`
- Фотографии: папка `assets`
- Кнопки записи ведут в Telegram Айзили

Проект сохранён в папке `aizilya` репозитория `irekgai111-lang/irke`.

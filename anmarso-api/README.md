# Сервер заявок ANMARSO — версия 2

## Что делает

1. Принимает заявку только с разрешённого сайта.
2. Проверяет имя, телефон, описание задачи и согласие.
3. Компания и ИНН необязательны.
4. Сначала сохраняет заявку в закрытый локальный журнал.
5. Затем отправляет уведомление на почту.
6. MAX, WhatsApp и DaData не блокируют основной приём заявок и подключаются позже отдельно.

## Проверка

```bash
node --check server.mjs
node --test server.test.mjs
```

## Обязательные настройки рабочего запуска

```text
DRY_RUN=false
REQUIRE_EMAIL=true
ALLOWED_ORIGINS=https://irekgai111-lang.github.io
DATA_DIR=/закрытая/папка/anmarso
MAIL_HOST=smtp.mail.ru
MAIL_PORT=465
MAIL_USER=Anmarsoms@mail.ru
MAIL_APP_PASSWORD=отдельный пароль приложения
MAIL_TO=Anmarsoms@mail.ru
```

Пароль приложения хранится только в закрытом серверном файле. В GitHub и код сайта он не добавляется.

## Важное условие

Форма действующего сайта подключается к серверу только после того, как `/ready` возвращает `200` и `ready: true`. До этого продолжает работать запасная ручная отправка через почту и WhatsApp.
